# 🛠️ Custom Claude Skills Toolkit

A collection of engineered prompt frameworks designed to turn Claude into a strict, rule-following assistant for specific professional workflows. 

Writing prompts from scratch every time takes too long and leaves room for AI hallucinations. To solve this, I engineered three plug-and-play `.md` files that force the AI into a structured two-phase workflow (Discovery & Execution). 

## 📦 What's Included?

### 1. The ATS-Friendly Resume Creator
Formats and structures resumes specifically to parse correctly in Applicant Tracking Systems (ATS). 
* **The Problem:** AI often over-formats resumes with tables and columns that break ATS parsers.
* **The Solution:** This skill forces clean layouts, proper keyword integration, and strict text-based hierarchy without adding fluff.

### 2. The UI/UX Web Developer
An expert UI/UX developer that refuses to write a single line of code until it asks intake questions.
* **The Problem:** AI jumps straight into coding without understanding brand identity or user goals.
* **The Solution:** Forces an intake phase, then strictly adheres to core UX laws (Hick's Law, Fitts's Law), typography constraints, and conversion principles for the final build.
* *(Note: Reference images for the UI/UX laws are included in this repository).*

### 3. The Presentation Intro Generator
Automatically generates five unique ways to open a presentation or speech based on the provided content.
* **The Problem:** Starting a presentation is often the hardest part, and AI usually gives a generic, boring opening.
* **The Solution:** This skill takes the main content of your slides or speech and provides five distinct, engaging introduction options to hook the audience right away.

## 🚀 How to Use These Skills

**Option 1: Upload as a Claude Skill (Recommended)**
1. Open Claude and click on your profile/settings menu.
2. Navigate to the **Skills** section.
3. Upload the downloaded `.zip` folder or individual `.md` file directly into the skills menu.
4. The skill is now saved and ready to use whenever you need it!

**Option 2: Claude Projects**
1. Open Claude and create a new Project.
2. Copy the contents of the desired `.md` file and paste it into the "Custom Instructions" box.
3. Upload any relevant reference images to the Project's Knowledge Base.

**Option 3: Direct Chat**
1. Open a new chat in Claude.
2. Upload the desired `.md` file (and any reference images).
3. Type your request (e.g., *"I want to build a website for my new idea"*) and watch the workflow begin.
